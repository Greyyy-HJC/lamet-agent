where $\xi = x/y$, $L = \ln(4y^2P_z^2/\mu^2)$, $\kappa$ is the scale-variation parameter (scanned over $0.8$–$1.2$ in the paper), and $\mu_{\rm min}$ is the perturbative cutoff (the paper's $x_{\rm min}$). The fixed-order kernel at the row's own scale is the NLO $\overline{\rm MS}$ coefficient of Eq. (2.14) of Ref. [2602.11283], with the plus-prescription at $\xi=1$ implemented by making each $y$-column integrate to zero. Rows with $2\kappa x P_z < \mu_{\rm min}$ are set to zero, implementing the paper's $x_{\rm min}$ cutoff.

The regular (off-diagonal) coefficient is
$$C_{\overline{\rm MS}}^{(1)}(\xi, L) = C_{\rm ratio}^{(1)}(\xi, L) + \frac{1}{2|\xi-1|},$$
with
$$C_{\rm ratio}^{(1)}(\xi, L) = \frac{\alpha_s C_F}{2\pi} \left[ \frac{1+\xi^2}{1-\xi} \left( L + \ln\frac{\xi}{\xi-1} \right) + \xi - 1 + \frac{3\xi-1}{\xi-1} \frac{\arctan\sqrt{1-2\xi}}{\sqrt{1-2\xi}} - \frac{3}{2|\xi-1|} \right] \quad (\xi<1/2),$$
and the $\arctanh$ branch for $\xi>1/2$, with the analytic limit at $\xi=1/2$. The plus-prescription is applied with the paper's notation: the coefficient is split into $[\,g(\xi)\,]^{[0,1]}_{+(1)}$ for $0<\xi<1$ and $[\,g(\xi)\,]^{(-\infty,\infty)}_{+(1)}$ for the full domain, with the $\delta(1-\xi)$ term carrying the diagonal subtraction. The scheme-specific finite correction is the $0.5(1+L)$ term added on the diagonal.

#### Consistency check

The code reproduces App. 'A Method Solving RG Equation' (Eq. matchingRGI) of arXiv:2209.01236 in structure: the per-row scale $\mu_0 = 2\kappa x P_z$, the DGLAP evolution to $\mu$, and the $x_{\rm min}$ cutoff all match the paper's description. The fixed-order base is the NLO $\overline{\rm MS}$ kernel of Eq. (2.14) of Ref. [2602.11283], which is not the paper's hybrid-scheme kernel (Eqs. (A.10)–(A.11) of the paper); the paper's hybrid kernel includes a $z_s$-dependent sine-integral term and a different plus-prescription domain, which the code does not implement. The code's `C_ratio` matches the paper's ratio-scheme kernel (Eq. (A.10)) in the regular region, including the $\arctan/\arctanh$ branch and the $L$ logarithm, but the paper's hybrid kernel adds the $z_s$-dependent term that is absent here. The plus-prescription notation in the code (column-sum subtraction) is equivalent to the paper's $[g]^{D}_{+(1)}$ but the paper's explicit split into $[0,1]$ and $(-\infty,\infty)$ domains is not reproduced in the code's single matrix construction. The two-loop splitting function in the code matches the standard NLL non-singlet kernel, but the paper's Eq. (matchingRGI) uses the DGLAP kernel $P[w,\alpha_s]$ without specifying its order; the code uses the full two-loop (NLL) form. No discrepancies in signs or log arguments were found in the regular coefficient; the only differences are the scheme (MSbar vs. hybrid) and the absence of the $z_s$ term.
